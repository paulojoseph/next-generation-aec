# 12. Glossary

**ID**: ARC42-12
**Status**: Approved
**Last Updated**: 2025-12-20

---

## Business Terms

| Term | Definition |
|------|------------|
| **AEC** | Architecture, Engineering, Construction - the target industry |
| **BIM** | Building Information Modeling - 3D models with metadata |
| **LiDAR** | Light Detection and Ranging - laser scanning technology |
| **Point Cloud** | Collection of 3D points from laser scan |
| **S3DIS** | Stanford 3D Indoor Semantics Dataset |

---

## Technical Terms

| Term | Definition |
|------|------------|
| **BufferGeometry** | Three.js geometry stored in GPU-friendly format |
| **LOD** | Level of Detail - rendering at variable resolution |
| **PLY** | Polygon File Format - point cloud storage format |
| **R3F** | React Three Fiber - React renderer for Three.js |
| **Raycasting** | Technique for detecting 3D object intersection |
| **Skip-rate** | Decimation factor (1/N points loaded) |
| **Smart Ghosts** | Visual snap candidates for measurement |
| **WebGL** | Web Graphics Library - browser 3D API |

---

## File Formats

| Format | Description |
|--------|-------------|
| **PLY** | Binary point cloud (18 bytes/vertex) |
| **GLB** | Binary glTF mesh format |
| **JSON** | Manifest and metadata |
